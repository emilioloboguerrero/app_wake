### Launch hardening (P0 + P1 + 2 deferred)

- **Paywall bypass #1** — `PATCH /users/me/courses/:id/status` accepted `"active"` for any courseId (self-grant). Now rejects `"active"` + requires the course to already exist. `functions/src/api/routes/profile.ts`. **Verified live: 403.**
- **Paywall bypass #2** — `users/{uid}` firestore.rules `create` had no field allowlist, so delete+recreate could self-grant `courses`/`role`/`trial_used`. Now field-allowlisted. `config/firebase/firestore.rules`.
- **Service worker never installed** since ~2026-05-01 — CSP `script-src` lacked the Workbox CDN. Added `https://storage.googleapis.com/workbox-cdn/` (path-scoped) to the `/app` CSP. `firebase.json`. **Verified live: SW installs, console clean.**
- **UTC date bugs** — "today" and completion date computed in the function's UTC clock; Colombia is UTC-5, so after 19:00 COL users got tomorrow's session / wrong-day completions. Now `bogotaMidnightToday()` / `bogotaTodayISO()`. `functions/src/api/routes/workout.ts`. **Verified live at 19:23 COL: session stored `date: 2026-07-03` while `completedAt` was `2026-07-04T00:22Z`.**
- **`POST /workout/complete` idempotency** — dedup on `completedAt`; a retry no longer writes a duplicate session. **Verified live: 2nd submit → `duplicate:true`, 1 sessionHistory doc.**
- **`exerciseKeys` misalignment** — `.filter(Boolean)` desynced keys from exercises; history/PRs wrote under the wrong exercise. Now index-aligned (`alignedExerciseKeys`).
- **wakeAlert helper** — `Alert.alert` is a no-op in react-native-web; 88 error/confirm dialogs were silently swallowed. New `apps/pwa/src/utils/wakeAlert.js` (native → Alert.alert) + `.web.js` (vanilla-DOM toast/modal). Swapped all 88 sites.
- **Silent swallows fixed** — offline queue full reported dropped writes as queued; onboarding save failure showed false success + lost the profile; Hoy showed "no programs" on a courses-load error.
- **Broken flows** — ProgramLibraryScreen retry called an undefined `fetchCourses`; event QR check-in hit the wrong endpoint + a field the public event API never returns; PaymentCancelledScreen dead-end got a "Volver a la app" button.
- **Creator IDOR** — `GET /creator/clients/:id` honored an unverified `?userId` hint → any user's profile. Removed. `functions/src/api/routes/creator.ts`.
- **creator-dashboard apiClient** — App Check token fetch now time-boxed + degrades (parity with PWA).
- **Email batch poison message** — one malformed recipient sank the whole 100-recipient Resend batch; now partitions invalid emails out. `functions/src/index.ts`.
- **Global mutation error handler** (creator dashboard) via `MutationCache` + `apps/creator-dashboard/src/utils/toastBridge.js`.
- **[Deferred, done] Resources leak** — `additional_resources` (paid PDF/link URLs) sat on the client-readable `courses/{id}` doc. Moved to gated `course_private_resources/{id}` (deny-all-client rule); reader dual-reads; `pickPublicCourseFields` prefers explicit `additional_resources_count`. **Prod migration ran** (Código ABS `ezJWUr3wJvaeptIM5f86`, 4 items; field deleted, count preserved). Migration script: `scratchpad/migrate-resources.js`.
- **[Deferred, done] Polar-on-publish** — `PATCH /creator/programs/:id/status` (how the dashboard publishes) never provisioned the Polar USD product → international checkout failed. Extracted `syncPolarProduct()` shared by the price editor and the publish toggle.
